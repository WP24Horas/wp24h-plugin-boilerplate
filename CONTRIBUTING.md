# Contributing

Thank you for helping improve the WP24H Plugin Boilerplate.

1. Open an issue for behavioral changes or new public APIs.
2. Create a focused branch from `main`.
3. Keep modules small and avoid hidden global state.
4. Add or update tests for changed behavior.
5. Run `composer check` locally.
6. Describe the motivation, implementation and validation in the pull request.

All contributions must follow the WordPress Coding Standards and remain compatible with the supported PHP range.
