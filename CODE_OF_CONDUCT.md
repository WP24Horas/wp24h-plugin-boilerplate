# Código de Conduta

O WP24H Plugin Boilerplate recebe contribuições de pessoas com diferentes níveis de experiência. Esperamos comunicação respeitosa, objetiva e construtiva.

## Comportamento esperado

- Discuta ideias e código sem ataques pessoais.
- Ajude novos colaboradores a compreender padrões e decisões.
- Respeite privacidade, autoria e diferenças de opinião.
- Evite assédio, discriminação, intimidação e exposição de dados pessoais.

Violações podem ser reportadas de forma privada para `contato@wp24horas.com.br`. Os mantenedores poderão moderar conteúdo ou participação para proteger a comunidade.
