# Security policy

## Supported version

Security fixes target the latest release on the `main` branch.

## Reporting a vulnerability

Do not disclose exploitable details in a public issue.

Use GitHub private vulnerability reporting when it is enabled for this repository. If it is unavailable, contact WP24Horas through <https://wp24horas.com.br> and include:

- affected version and environment;
- reproduction steps or proof of concept;
- expected impact;
- suggested remediation, if known.

Please allow reasonable time for validation and coordinated disclosure.
